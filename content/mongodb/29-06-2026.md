BSON is binary JSON. It is an extension of JSON. It is the binary encoded serialization format to store and transfer data in MongoDB.

BSON is machine optimized and light-weight format that traverses faster than JSON.

Apart from JSON data types, it supports additional data types such as Object ID, Timestamps and Date.

MongoDB Document has the following limits -

- Document should not be more than 16MB
- There should not be more than 100 levels of nesting.
