TaskOrbit backend exposes `/auth/login` and `/auth/google/login` routes for authentication. Both APIs generates access and refresh token during login. The access token is valid for 15 minutes and refresh token is valid for 1 week.

The success response for both APIs has the following structure:

```json
{
    "status": "success", 
    "data": {
        "access_token": "...",
        "expires_at": "19-05-2026T12:00:00Z",
        "user": {
            "user_id": "...", 
            "username": "...", 
            "email": "...",
            "display_name": "...", 
            "avatar_url": "..."
        }
    }
}
```
